# Restaurant Tip Analysis Using Excel

## About the Project

This project is based on a restaurant tips dataset. The aim was to analyze the factors related to the tip amount and use a regression model to predict tips.

I completed the analysis in Microsoft Excel, starting with data preparation and ending with regression and prediction.

## Dataset

The dataset contains **243 observations** with information about restaurant bills, customers, and tips.

Main columns include:

- Total Bill
- Tip
- Sex
- Smoker
- Day
- Time
- Size

## What I Did

### 1. Data Preparation

Prepared the dataset for analysis and converted categorical values into numerical values where required for regression.

### 2. Correlation Analysis

Calculated correlations between the variables to understand their relationship with the tip amount.

### 3. Regression Analysis

Used **Multiple Linear Regression** to predict the tip amount using:

- Sex
- Smoker
- Day
- Time
- Total Bill
- Size

### 4. Prediction and Error Analysis

Calculated the predicted tip for each observation and compared it with the actual tip.

Also calculated:

- Error
- Squared Error

## Regression Results

| Metric | Value |
|---|---:|
| Multiple R | 0.6844 |
| R Square | 0.4684 |
| Adjusted R Square | 0.4549 |
| Standard Error | 1.0226 |
| Observations | 243 |

The model has an **R² value of 0.4684**, meaning that the variables included in the model explain about 46.84% of the variation in tip amount in this dataset.
